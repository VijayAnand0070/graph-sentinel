# Project report (REC format, Department of Artificial Intelligence and Machine Learning)

Deliverables: `D:\GraphSentinel_Project_Report.docx` and `D:\GraphSentinel_Project_Report.pdf`
(90 pages: 13 front-matter pages i-xiii, chapters 1-6, references, appendices I-VI).
Department pages (vision, mission, PEOs, POs, PSOs) follow the official R2023 AIML curriculum;
course code AI23721 (Project Phase-I) is highlighted for confirmation (AI23821 if Phase-II).

| File | Role |
|---|---|
| `rc_ch1.py` ... `rc_ch6.py` | chapter text, tables, figure and equation placements |
| `rc_front.py` | cover, certificate, acknowledgement, abstract, abbreviations, department pages, CO-PO / CO-SDG |
| `rc_refs.py`, `rc_eqs.py` | references (verified) and native Word equations (generated by `make_refs_eqs.py` from the paper) |
| `report_build.py` | writes the .docx (sections with roman/arabic page numbers, PAGEREF-based contents lists) |
| `report_export.py` | opens in Word, updates fields, saves native .docx and PDF |
| `report_figs.py` | architecture, DFD, use case, sequence, methodology, agent, training and detector charts |
| `shoot*.py`, `prep_shots.py` | console screenshots from the running service (`.claude/launch.json` "api") |

Rebuild (needs the paper figures in `../paper/figs` and the paper PDF on D:\ for Appendix III):

```bash
python report_figs.py
python report_build.py
python report_export.py D:/GraphSentinel_Project_Report.docx
```

Highlighted yellow text marks items to confirm or fill in (course code/phase, register numbers,
qualifications of the supervisor and coordinator, month/year, course objective and outcomes,
plagiarism reports, proof of publication). The CO-PO values in Appendix V are a proposal to be
checked and signed by the supervisor. The demonstration screenshots in Section 5.2 are not an
evaluation; events from host C17693 in the demo stream are labelled benign.
